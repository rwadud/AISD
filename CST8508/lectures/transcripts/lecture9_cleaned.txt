Object tracking is a fundamental task in computer vision, like classification and detection. It involves the identification and tracking of an object. The algorithm identifies the object and then tracks that object across different frames of the video. Examples of applications include surveillance for security, traffic monitoring, and sports analytics, where object tracking is used to support decisions.

Object tracking is done in three main steps. First is object detection: we need to detect the object present in the image or the video. After detection, we get a bounding box around that object. For example, in the image shown, there is a bounding box around the football because object detection identified the ball and created a bounding box around it. The second step is that the algorithm assigns a unique ID to that object. For example, ID 1 is assigned to that object. In the third step, tracking happens. We track the detected object as it moves through frames. A video is made up of multiple frames, and in each frame, this ID or this object is being tracked. So the main idea of object tracking is: detect the object, assign an ID, then track it across multiple frames of the video.

Now let's look at the differences between tracking and detection. Detection tells us where exactly the object is present in an image. Object tracking is the ability to estimate or predict the position of a target object in each consecutive frame of the video. So it tells you what the position of that object will be in the next frame. Object detection works on a single frame of the video. It is useful only for detecting whether the object is present in an image or a single frame of the video, and it does not track the object across consecutive frames. Object tracking keeps track of the object across multiple frames. However, detection will only work if the target object is visible; if it is hidden by any interference or another object, detection cannot identify the object in the frame. Object tracking is trained to track the trajectory of the object despite occlusions.

So detection works on images or a single frame of the video, but tracking runs on consecutive frames of the video. Tracking can detect and also predict the position of the object in the next frame.

Challenges. The input for tracking is video, not just images, so it is more complex. The challenges are different from those in object detection. The main challenge is dealing with moving objects. Human motion is sometimes slow and sometimes rapid, so depending on how fast it is, tracking is very difficult. You can see people moving very fast in a stadium, and it is very hard for a computer to keep track of them. The system needs to identify them in the video and assign a unique ID. As some objects fade away from the camera, it is very hard to keep tracking each of them, especially in a crowded scene.

Other challenges include rapid object movements and changes in size. When an object is closer to the camera, it appears bigger, and as it moves farther away, it appears smaller. There are also shape changes and occlusions. If a person is hidden by another, it is hard to keep tracking them. Varying lighting conditions are also a challenge. Additionally, real-time processing is required. For object tracking, we need fast responses for real-time applications, and giving that response with high accuracy is not an easy task. So that is the difficulty of object tracking, especially in real-time processing environments. Maintaining the consistency and accuracy of the object's identity over time is also hard. As some objects move farther away, the system may lose the ID, and IDs may switch between people walking together.

Looking at specific challenges in the example images: illumination, where changes in lighting make it hard to track a person because part of a face is more highlighted than another part, and the system struggles to track that person across frames of the video. Occlusion, where one person's face is hidden by another, so it is hard for the system to identify and track that person. Deformation, where the shape of the object is not normal. Noise corruption, where video is affected by noise. Out-of-plane rotation, where a person or object is rotated out of the camera plane. And motion blurring, where fast-moving objects have a lot of blur, and it is hard for the system to keep track of each person in the image.

In spite of these challenges, there are techniques for object tracking. There are different types: single object tracking and multiple object tracking. Single object tracking, as the name indicates, focuses on a single object. We focus on monitoring the movement of a single object within the video. Other objects present in the frame are not considered; it just focuses on one object. The challenge is maintaining the identity of the object despite changing appearance, scale, and occlusion. Sometimes the object can be occluded by another object, and it may appear at different scales: when the ball approaches, it appears bigger, and when it is farther away, it appears smaller. If there are two similar objects, such as two balls, it can be a challenge because their appearance might not exactly match, so the system has to identify the particular one, but we have algorithms that handle that.

Techniques for single object tracking vary from simple bounding box tracking to more sophisticated methods involving feature extraction, like in CNNs, and motion prediction. So single object tracking focuses only on one object throughout the video.

In multiple object tracking, we track multiple objects. It focuses on many objects at the same time, simultaneously tracking multiple objects present in the video. In the example video, there are a number of cars, and the system can detect every car present and assign a specific ID to each car. The system should manage the identities of similar-looking cars and maintain a unique ID for each object. The ID cannot change or be swapped between objects. This is particularly challenging in crowded scenes. Occlusions, where one object is hidden by another, make it harder. Similar appearances also make it challenging, because if there are two similar objects in the video, it is very challenging for the system to give a unique ID to each object and keep track of them.

Comparing single and multiple object tracking. Multiple object tracking is more complex because we need to keep track of multiple objects, while in single object tracking, we focus only on one. The main challenge with both systems is managing object motion and interactions, especially in multiple object tracking, where multiple objects interact with each other. At that time, it is very hard for the system to maintain identities. Similar appearances are another challenge. Achieving multiple object tracking with 100 percent accuracy is not simple. MOT requires sophisticated algorithms to distinguish and maintain the identity of each object across frames.

Complexity in multiple object tracking comes from several factors. One is dynamic object count: the number of objects in the video is not constant and dynamically changes. Some people enter the scene and some leave, so the number of objects keeps changing. Another is varying object size and non-linear motion. People do not always move in a straight line; they can move in any direction. Environmental conditions also add complexity. The tracker must be able to detect new objects entering the scene, handle objects that disappear, and handle reappearance. When an object leaves the scene and reappears, the system should identify that object with the same ID assigned earlier. It should not treat it as a new object. For that, we use a technique called re-identification (ReID). Without re-identification, when an object leaves and reappears, it would be treated as a new object, and the continuity of tracking across frames would be lost. Re-identification assigns the same ID to the object even if it reappears. The system stores information about each object, so when it reappears, it can match to previously stored data. So the tracker must handle new object appearances, disappearances, and maintain consistent tracking across frames, and ensure accurate identity assignment. It cannot treat three people walking together as a single person; it should assign different IDs to each person even if they walk closely.

Traditional methods helped with object tracking to some extent, but they were not great, so we needed more sophisticated methods. One example is background subtraction. We feed the system training frames along with the background. We subtract the background from each frame, which leaves only the object. Then we apply a threshold to produce the output mask. This is one traditional method to detect an object: subtracting the background from the frames. Traditional methods relied on techniques like background subtraction, optical flow, and frame differencing. These approaches used handcrafted feature extraction methods. Such systems were suitable only for scenarios with limited object movement and minimal occlusion. They struggled in complex dynamic environments, where the background is changing or the object is moving fast. Because of that, we had to develop more advanced tracking methods, which is how we ended up using deep learning techniques for multiple object tracking.

In deep learning-based multiple object tracking, we have techniques like convolutional neural networks that can automatically learn patterns from data. Deep learning-based trackers use CNNs to learn feature representations directly from data. As a result, we get more robust trackers that can still track objects even with occlusion, orientation differences, and lighting variations. These models can handle complex object interactions and variations in appearance more effectively than traditional methods.

Advantages of deep learning for MOT: CNNs can automatically learn rich features hierarchically. This provides superior object recognition and tracking. They can better detect the object and keep track of it. They also handle large-scale variations: even if the same object appears at different scales in different frames, they can still match it. Even with partial occlusion by another object, they can still handle it. Complex motion patterns are also handled to some extent. So deep learning provides significant improvements over traditional methods. With the introduction of CNNs, we could develop much better systems that overcome the limitations of traditional methods. Another advantage is that deep learning methods give more accurate, robust results than traditional methods.

Different types of trackers. We have single object tracking and multiple object tracking. Single object tracking focuses only on one object, and multiple object tracking focuses on multiple objects simultaneously in consecutive frames of the video. We also have different types of trackers based on architecture: single-stage trackers and two-stage trackers. In a single-stage tracker, a single stage performs both detection and tracking. The three main steps of object tracking are detection, assigning a unique ID to the detected object, and tracking. In a single-stage tracker, detection and tracking both happen together. As shown in the image, the CNN takes the input, and it produces both detection and ID simultaneously. Re-identification also happens: if an object leaves and reappears, it can be given the same ID it had earlier.

So in a single-stage tracker, both detection and tracking happen simultaneously. The output includes bounding box, object ID, and frame ID. Because single-stage trackers perform detection and tracking simultaneously, they run at high speed, which is useful for real-time applications. The drawback is that we compromise on accuracy; accuracy is not that great in such systems.

Another solution is two-stage trackers. In a two-stage tracker, we first do the detection. As a result of detection, we get the objects detected from the video. Then we use those detections to track the objects across frames. This happens in two different stages, not simultaneously like in single-stage trackers. Two-stage trackers separate the detection and tracking phases. First, they detect the object in each frame, then they associate those detected objects over time. The issue with two-stage trackers is that they are computationally intensive. They are not as fast as single-stage trackers because tracking happens after detecting all the objects. However, they achieve higher accuracy than single-stage trackers. Two-stage trackers are especially useful for crowded or complex scenes. Even with very crowded input, the accuracy is much higher in two-stage trackers.

An example of a single-stage tracker is DeepSORT. DeepSORT is designed for speed and efficiency. The output includes the object class the object belongs to, the unique ID, and the location of the object in each frame. All of this is obtained in a single network pass, which is why it is a single-stage detector: it does both detection and tracking at the same time. DeepSORT is suitable for real-time tracking, but accuracy is not great. It struggles with small or partially occluded objects and often requires fine-tuning for specific tracking scenarios.

In a two-stage tracker, tracking happens in two different phases. The first phase is detection, and the next phase is association. Examples of two-stage trackers are ByteTrack and OC-SORT. ByteTrack was introduced recently. A two-stage tracker first uses a CNN-based detector to detect objects in each frame. The second stage involves an association algorithm to predict the position of the object in the next frame. Techniques include Kalman filter and Hungarian algorithm. I'll share reading material about how Kalman filter works, so you can read through it in detail. These are association algorithms widely used to associate the detected objects across frames. The two-step approach enhances tracking accuracy. It is slower, but it gives higher accuracy than single-stage trackers. Especially when there are object interactions in the video, two-stage trackers are very helpful, even with occlusion.

Discussion: which is better, single-stage or two-stage MOT models? There is no single correct answer. It depends on your use case. If you are looking for high speed, for example for an edge device application, you should use single-stage. Edge devices require fast responses and cannot wait, so single-stage is the right choice. But if you are developing applications that require higher accuracy and can compromise on speed, choose two-stage MOT trackers. For crowded environments or occlusion, two-stage MOT trackers are better because they detect objects more accurately in such complex scenarios.

Deep learning models for object detection. We now focus on multiple object tracking because most complex scenarios require it. For edge devices, we focus mostly on single-stage trackers. Single object tracking focuses only on a single object, but in most cases, we need to track multiple objects. In MOT, deep learning models for object detection play a crucial role. The first step is object detection. Examples are Faster R-CNN, YOLO, and SSD. These provide robust and accurate object detection. You should carefully select the detection model because only if you can detect all the objects present in the video frame can you track them. Make sure the object detection model is a good choice; it is the first step in tracking.

These models, such as Faster R-CNN, YOLO, and SSD, differ in how they detect objects. Faster R-CNN uses a technique called region proposals for more accurate localization, while YOLO and SSD predict bounding boxes and class probabilities directly from the image. In YOLO, the image is divided into different grids, and for each grid, we get bounding boxes and class probabilities. So the approach differs, but the idea is that they all perform object detection.

The next step is tracking. We need to use association algorithms. If a given object is present in one frame but not in the next, we can predict the location of that object in the upcoming frame. In two-stage trackers, after detecting the objects, box association algorithms perform the tracking. Some techniques are Hungarian algorithm, Kalman filter, and IoU (Intersection over Union). IoU gives an idea about how much your prediction overlaps with the ground truth; the higher the overlap, the better. These techniques associate detections across frames based on spatial and appearance similarities. Even with multiple objects, we identify each object and check where that object is present in the frames. Based on the pattern of motion or the object's trajectory, the system can predict where it will be in the next frame. These algorithms handle challenges like occlusion, updating identity, and variations across frames. The Kalman filter predicts the position of the object in the next frame. The Hungarian algorithm matches predictions with detected objects; given a row of detected objects, it looks for the best match with the prediction from the next frame. All these algorithms work together to perform the association. So after detection, we have association. Finally, we get better detections with bounding box coordinates, ID, class, and confidence score.

Now let's look at ByteTrack in detail. You can use ByteTrack for your project if you want. ByteTrack stands out as a unique, innovative approach in multiple object tracking. It is one of the popular ones. It is designed to handle complex scenarios with high accuracy, even occlusion or crowded scenes. It can also maintain real-time performance. It is not as fast as single-stage trackers, but it maintains real-time performance. ByteTrack is one of the popular two-stage trackers. It combines a high-performance detector with the ByteTrack algorithm. It first uses a detector like YOLO, then performs association of the detected object boxes with existing tracks. ByteTrack can manage object identities even in crowded scenes. Even with occlusion or crowded input video, ByteTrack handles it to some extent. It has shown remarkable results in tracking multiple objects in challenging environments. ByteTrack uniquely identifies and keeps track of multiple objects even in complex scenarios.

ByteTrack is a multiple object tracking algorithm that enhances tracking accuracy by associating every detection box, including those with low detection scores. The first step is object detection. The output of detection gives us objects with bounding boxes, a confidence score for each box, and the class of each detection. ByteTrack considers both high-confidence detection boxes and low-confidence detection boxes.

Step one of ByteTrack is object detection. It takes each video frame and uses a detection model like YOLO or Faster R-CNN to detect objects. The output is bounding boxes with associated confidence scores and coordinates.

The next step is data association, which is the core of ByteTrack. This is where tracking happens. We associate detected objects across frames. Data association uses two stages.

In stage one, we focus on high-confidence detection boxes, those above a certain threshold, for example 0.5. The threshold depends on your application and is configurable. High-confidence detection boxes are matched with existing tracklets. Tracklets are short sequences of frames where an object has been consistently detected. We know the coordinates of this object across all the frames. We match high-confidence detection boxes with tracklets. The advantage is that we match the most reliable detections to the right tracklets.

In stage two, we focus on low-confidence detection boxes, those below the threshold. We give importance to low-confidence boxes. This stage helps us recover true objects that we might have missed in stage one. It ensures that we do not miss any important objects. These are matched with tracklets based on similarity. The similarity is measured using Intersection over Union (IoU) and appearance features, using cosine similarity from deep learning. So data association happens in two stages: stage one focuses on high-confidence detection boxes, and stage two focuses on low-confidence detection boxes. This ensures that important objects are not missed.

Next is a gating mechanism. After detection and association, the gating mechanism filters out redundant detections. It looks for any redundant or duplicate detections and ensures that only relevant detections are considered for tracking. This is the stage where we filter out redundant detections.

Performance: by considering all detections, ByteTrack achieves high tracking accuracy and robustness, because we make sure that we have detected all relevant objects. ByteTrack is useful for applications like surveillance, autonomous driving, and sports analytics.

ByteTrack's methodology combines deep learning-based detection, using models like YOLO or Faster R-CNN, with an efficient association strategy, the ByteTrack algorithm. It leverages the strength of YOLO as a detector and an innovative association that is fast and robust. In the diagram, for the example frame, tracklets are identified from high-confidence detection boxes. We focus only on high-confidence detections in that stage and ignore low-confidence ones temporarily. In the next stage, we add the low-confidence detections, so all relevant objects are covered. In performance evaluations, ByteTrack has demonstrated superior tracking accuracy compared to other models and outperforms many existing methods on standard MOT benchmarks.

Application scenarios for MOT. There is a wide range of applications. One is urban traffic management: MOT helps in vehicle and pedestrian tracking for safety and flow optimization, and can be used in autonomous vehicles. In retail, MOT can analyze customer behavior and store traffic. One example during COVID was that stores allowed only a specific number of people inside, so by tracking people entering and leaving, they counted the number of people inside and let people in accordingly. In sports analytics, MOT is used in competitions to track player movements and the movement of the ball or target. MOT also plays a vital role in surveillance systems for monitoring and security. So MOT has a wide range of applications, including real-time traffic management, border checks, and subways.

Current challenges and limitations. Despite advancements in MOT with sophisticated algorithms like ByteTrack, YOLO, and combinations of techniques, MOT still faces challenges. Dense crowds and frequent occlusions are still a challenge. Although MOT handles them to some extent, dynamic environments with heavy crowds and occlusion remain challenging. Differentiating similar-looking objects is hard: when two objects look like the same person in the video, the system struggles to distinguish between them. Ensuring accurate long-term tracking is another challenge. Objects may come in, leave, and reappear, which is why re-identification is useful: when an object reappears, we should not identify it as a new object but give it the same ID as before.

Additionally, the computational demands for processing high-resolution videos are significant. The input for object tracking is video, not images. With HD or high-resolution videos, we need significant computational capacity to process them in real time. Another challenge is diverse datasets. Unlike image data, video data, especially with annotations, is not easily available. For supervised learning, we need annotated datasets where each object present in the video is labeled for training. So providing such annotated datasets is a challenge, as is providing diverse data. Addressing these challenges is crucial for progress in MOT technologies, especially with video, where we need significant computational capacity.

Future trends. MOT can be integrated with other AI technologies like deep learning and reinforcement learning for more sophisticated tracking. There is a focus on developing low-latency, high-accuracy models suitable for edge computing. As mentioned, we need systems that are both fast and accurate; we cannot compromise one for the other. The main focus is on developing such systems with low latency and high accuracy. Another trend is the use of semi-supervised and unsupervised learning techniques to reduce dependency on large annotated datasets, since providing annotated data is not easy. The integration of MOT with technologies like drones and autonomous vehicles is already happening and is a key area for future development.

Hands-on techniques for MOT. The first step is data preparation, a critical step in MOT, as in any machine learning task for classification, detection, or tracking. Without good data, accuracy will not be high. This involves collecting and annotating video data, ensuring a variety of scenarios and object types are represented. You should have a diverse dataset representing different real-world situations so the model can handle real-world conditions. If you feed biased data, the model will behave accordingly and will not react correctly in other scenarios. So always have a diverse, unbiased dataset for training.

Data augmentation can expand the dataset. Techniques like random cropping, scaling, and flipping increase dataset diversity. As we saw earlier, from a single image of a cat, you can generate hundreds of images by resizing, cropping, or flipping vertically or horizontally. The same applies to object tracking. Preprocessing is also essential, including normalization and format conversion. Sometimes you need format conversion to match the format expected by the model. These are essential for preparing data for deep learning models.

Next is model training. Once data is prepared, model training is the next step. You need to select the right architecture. For single-stage trackers, select the right architecture for the end-to-end tracker. For two-stage trackers, select the best object detector such as YOLO or Faster R-CNN. Hyperparameter tuning is also critical. Hyperparameters like learning rate, batch size, and number of epochs are crucial for optimal performance. Set them initially and then tune them.

You can use transfer learning. If many algorithms already exist in this area, you can transfer from those established models and adapt them to your application. Using pre-trained models significantly improves training efficiency and accuracy, especially with limited data. You do not have to have a large dataset to train your model, because you are using a pre-trained model that has already been trained on many different scenarios. You can transfer that knowledge to your application. For two-stage trackers, you also have to tune hyperparameters for box association. Tuning happens in both detection and association.

Evaluation and tuning is the last step. First, you prepare the data, then train the model, then evaluate. You cannot simply develop a system and trust it; you need to make sure it performs well on real-world inputs. Metrics for evaluating MOT models include MOTA (Multiple Object Tracking Accuracy), MOTP (Multiple Object Tracking Precision), and IoU (Intersection over Union). These metrics help measure the performance of your MOT model. Cross-validation and analyzing failure cases are also important. We learn from failure cases to understand model performance and further tune the model. Based on the results, you continue tuning and updating the model. When you encounter new scenarios or new data, you can fine-tune your system to get a more robust solution.
