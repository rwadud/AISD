Now let's talk about the different ways of fine tuning.

You can always do full fine tuning. You have some data, and let's say you want to fine tune your model to adapt to the domain of law. You have some data, and you can always train on top of your already pre-trained model. But there are two problems when you do that. It has to update all parameters, and that can lead to what is called catastrophic forgetting. What can happen is that whatever the LLM has learned before can completely fail. This is a very interesting thing.

If you try to do a full fine tuning with the new data: if you include the old pre-trained dataset and add the new dataset and do the full fine tuning, it is fine. But if you don't include the pre-trained dataset, you take just a new dataset, and you update all parameters by full fine tuning, most of the time it will forget what was there before. It does not retain the old data because it updates the weights. Also, it is expensive, because that kind of training will cost thousands of dollars.

So people use something called an adapter. They don't do a full fine tuning; they do what is called low-rank adaptation. Low-rank adaptation means: think of your pre-trained model parameters. Each layer is one row, and each neuron weight in each layer is like a column. You can think of it as a matrix or tensor, because the parameters would be multiple dimensions. Now, you freeze these model weights; you do not touch them. So you have the original matrix W, which you don't touch. Now, you then select only some layers in that, or some neurons in those layers, and you train those.

The updated weight matrix is equal to the original weight matrix plus another matrix delta W, so W prime equals W plus delta W. Now that delta W, any matrix can be factorized as the product of two lower-rank matrices. That is, if you have a matrix of size m by n, you can decompose it as the product of a tall matrix m by k times a thin matrix k by n. Those two matrices are small if you choose k small.

So you only train a small matrix of size m by k and k by n; then that matrix you keep separately, and at the time of loading the model into memory, you take that matrix and add to the original. So that is the updated weight. You update the weight while you are loading the model. You don't touch the original weight.

You can keep different adapters for different domains. I can take the same LLM and fine tune, create an adapter for the domain of law, create another adapter for the domain of healthcare, another adapter for the domain of fintech or cybersecurity. Fine tuning means generate the adapters. Then, depending upon the application, you can switch the adapters. The original model is the same, so you load the original model weight, you load that adapter for that domain, add that, and that is the new weight that you then use to create your neural network and do inference. Then you pass the query to the model.

These adapters are small; they are like a few MB, not even GB. Your original model is like GB; adapters are very easy to store. Fine tuning, creating adapters, you can do with small datasets, like maybe 10,000 or 1,000,000, and you can do it in a couple of hours on a small GPU. Not a small GPU, because you still have to load the whole model. Suppose your original model is a small model like LLaMA 8B or LLaMA 3B. When you load that model, it loads every weight, because it has to keep a copy of the data. So totally you need memory, and if you put everything together, if you want to fine tune a model of 3 billion parameters, that will come to about 24 GB. But still, that can be done on a single small GPU. You don't need a new computer.

So these are the advantages of using fine tuning.
